# itda-hyve 설치 가이드

Claude Desktop(Cowork) 이 내 PC 의 네트워크로 웹을 읽고 메일을 주고받게 해 주는 작은 프로그램입니다. 설치 파일 하나로 끝나며, 10분이면 됩니다.

## 준비물

- Claude Desktop (macOS 12 이상 또는 Windows 10/11)
- 메일 계정의 **앱 비밀번호** (일반 비밀번호가 아닙니다)
  - 네이버: 메일 > 환경설정 > POP3/IMAP 설정에서 IMAP 사용 → 2단계 인증을 켰다면 "애플리케이션 비밀번호"
  - Gmail: Google 계정 > 보안 > 2단계 인증 > 앱 비밀번호(16자리)
  - 다음/카카오: 메일 환경설정 > IMAP/POP3 사용 → IMAP 전용 비밀번호
  - iCloud: appleid.apple.com > 로그인 및 보안 > 앱 암호
  - 네이트: 메일 > 모바일 관리 > IMAP 사용 체크 (일반 비밀번호 사용)

## 1. 설치

아직 코드 서명을 하지 않은 판이라 처음 열 때 macOS·Windows 가 경고합니다. 아래 방법으로 한 번만 넘기면 됩니다.

### macOS

1. 내 Mac 에 맞는 파일을 받습니다 — [Apple Silicon(M1 이후)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-darwin-arm64.app.zip) 또는 [Intel](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-darwin-amd64.app.zip). 늘 최신 판이 받아집니다. 어느 쪽인지 모르면 왼쪽 위  > 이 Mac 에 관하여 > 칩 항목을 봅니다(Apple M… 이면 Apple Silicon).
2. 압축을 풀고 `itda-hyve.app` 을 **응용 프로그램** 폴더로 옮깁니다.
3. 처음 열면 "Apple 이 … 악성 코드가 없음을 확인할 수 없습니다"(macOS 14 이하는 "확인되지 않은 개발자") 창이 뜹니다. **완료**(또는 취소)를 누른 뒤 시스템 설정 > 개인정보 보호 및 보안 > 아래쪽 **"그래도 열기"** → 암호 입력 → 다시 뜨는 창에서 **열기**. 한 번만 하면 됩니다.

### Windows

1. 내 PC 에 맞는 파일을 받습니다 — [Windows (Intel·AMD, 대부분의 PC)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-windows-amd64.zip) 또는 [Windows on ARM (Snapdragon 등 ARM PC, Mac 의 Parallels)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-windows-arm64.zip). 늘 최신 판이 받아집니다. 어느 쪽인지 모르면 설정 > 시스템 > 정보 > **시스템 종류**를 봅니다("ARM 기반 프로세서" 면 ARM). 그래도 모르겠으면 첫 번째 파일을 받으세요 — ARM PC 에서도 돌아갑니다(조금 느릴 뿐입니다). 압축을 풀고, `itda-hyve.exe` 를 `%LOCALAPPDATA%\Programs\itda-hyve\` 에 둡니다(탐색기 주소창에 `%LOCALAPPDATA%\Programs` 를 입력하면 열립니다. `C:\Program Files` 는 관리자 권한이 필요해 회사 PC 에서 막히기 쉽습니다). (한 번 둔 뒤에는 옮기지 마세요. Claude Desktop 에 이 경로가 등록됩니다.)
2. "Windows 의 PC 보호" 창이 나오면 "추가 정보" > "실행".

## 2. 계정 등록

1. `itda-hyve` 를 실행합니다. 창이 하나 뜹니다. 처음 실행하면 `~/.itda/` 폴더와 열쇠 파일이 만들어집니다.
2. **계정** 탭에서 제공자(네이버, Gmail, …)를 고르면 서버 주소가 채워집니다. 이메일 주소와 앱 비밀번호를 넣습니다.
3. **연결 테스트** 를 눌러 IMAP·SMTP 모두 "성공" 인지 확인합니다. 실패하면 표시된 메시지를 보고 앱 비밀번호·IMAP 사용 설정을 다시 확인합니다.
4. **저장**. 비밀번호는 암호화된 파일(`~/.itda/hyve/vault.enc`)에만 저장되고 설정 파일에는 남지 않습니다.

## 3. API 키 등록 (쓰는 스킬이 있을 때만)

공공데이터·검색 같은 스킬은 발급받은 API 키가 필요합니다. **시크릿** 탭에서 넣습니다.

1. **새 값 등록** 을 누르고 목록에서 필요한 키를 고릅니다. **발급처 열기** 로 키를 받습니다.
2. 받은 키를 값 칸에 붙여넣고 **저장하고 확인** 을 누릅니다. 보내는 곳(허용 호스트)은 자동으로 채워집니다. 이미 등록한 값은 표의 **수정** 으로 바꿉니다.
3. 여러 개를 한 번에 넣으려면 `.env` 내용을 통째로 붙여넣으세요(Ctrl+V / Cmd+V). 무엇이 추가·변경되는지 먼저 보여주고, **반영** 을 눌러야 저장됩니다.

Claude 는 이 값을 볼 수 없습니다. 요청을 보낼 때 itda-hyve 가 채워 넣고, **그 키에 허용된 주소로 나갈 때만** 채웁니다. 대화에서 Claude 가 API 키를 물어보면 알려 주지 말고 이 화면에 넣으세요.

## 4. Claude Desktop 에 등록

1. **Claude Desktop** 탭 > **등록** 을 누릅니다(이미 등록돼 있으면 버튼이 비활성입니다). 설정 파일에 이 프로그램의 경로가 기록됩니다(기존 설정은 보존, 백업 자동 생성). 같은 화면 아래 **이 설정 파일에 등록된 MCP 서버** 표에서 결과를 확인할 수 있습니다.
2. 화면 위에 노란 배너가 뜹니다. **Claude Desktop 을 완전히 종료했다가 다시 엽니다.** 창만 닫으면 안 됩니다 — Windows 는 트레이 아이콘에서 종료, macOS 는 ⌘Q.
3. 새 대화에서 "등록된 메일 계정 알려줘" 라고 물어보세요. 계정 이름이 나오면 성공입니다.

(선택) 같은 탭의 **Aside 연결** 에서 Aside 브라우저의 CLI 를 찾아 함께 등록할 수 있습니다. 브라우저 자동화가 필요한 스킬이 사용합니다.

## 5. 사용

Cowork 에서 email / web-reader 스킬이 이 프로그램을 통해 동작합니다. 예:

- "네이버 메일 안 읽은 거 보여줘"
- "3번째 메일 읽어줘"
- "그 메일에 '내일 참석하겠습니다' 라고 회신해줘" → Claude 가 미리보기를 보여주고 확인을 받은 뒤 보냅니다.
- "이 링크 내용 정리해줘 https://…"
- (macOS) "codex에게 해바라기 밭 수채화 한 장 그려 달라고 해줘" → 에이전트 탭에서 codex 를 설치·로그인해 두면 내 ChatGPT 구독으로 이미지를 만들어 연결 폴더에 저장합니다. 약 1분 걸리고, 기다리는 동안 진행 상황을 한 줄씩 알려 줍니다.

Cowork 가 **"Claude가 itda-hyve에서 … 을(를) 사용하려고 합니다"** 창을 띄우면 **항상 허용** 을 권장합니다. 특히 이미지 생성은 작업 상태를 여러 번 확인하므로, 매번 "한 번만 허용" 을 누르면 그때마다 멈춥니다. 메일 발송·일정 삭제처럼 되돌릴 수 없는 일은 도구가 따로 미리보기를 보여 주고 확인을 받습니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| Claude 가 "도구가 없다" 고 함 | 4단계 등록 후 Claude Desktop 을 다시 시작했는지. **상태·로그** 탭에서 등록 경로 확인 |
| "secret_missing" 이라고 함 | 그 이름의 키가 아직 없습니다. 3단계에서 등록하세요 |
| "secret_host_denied" 라고 함 | 그 키가 이 주소로는 나가지 않게 막혀 있습니다. 시크릿 탭에서 **허용 호스트** 를 확인하세요 |
| 연결 테스트 IMAP 실패 | 앱 비밀번호가 맞는지, 메일 서비스에서 IMAP 사용을 켰는지 |
| 연결 테스트 SMTP 실패 | 같은 비밀번호로 IMAP 은 되는데 SMTP 만 안 되면 제공자 설정의 SMTP 포트(465/587) 확인 |
| 메일이 반송됨 | 보낸 사람 주소가 계정 주소와 같은지(별칭 발송은 지원하지 않음) |
| 프로그램을 옮겼더니 안 됨 | **Claude Desktop** 탭에서 **등록**(경로 갱신) 후 재시작 |

**상태·로그** 탭의 감사 로그에 모든 호출이 시각·도구·대상·결과로 남습니다(본문·비밀번호는 기록되지 않음). 문의할 때 이 화면을 캡처해 보내면 빠릅니다.

## 삭제

1. **Claude Desktop** 탭 > **등록 해제** 를 누릅니다. 이 항목만 지워지고 다른 서버와 나머지 설정은 그대로 남으며, 지우기 전 백업을 만듭니다. (Aside 도 같은 화면에서 해제할 수 있습니다.)
2. 앱 삭제. 설정 폴더 `~/.itda/hyve`(Windows `%UserProfile%\.itda\hyve`)를 지우면 저장된 값까지 사라집니다.
3. `~/.itda/master.key` 는 다른 itda 프로그램도 함께 쓰는 열쇠입니다. **다른 itda 프로그램을 쓰고 있다면 지우지 마세요.** 지우면 그쪽에 저장된 값도 열리지 않습니다.

## 위치와 출처 표시

"여기 날씨" 처럼 현재 위치가 필요한 스킬은 itda-hyve 에 위치를 묻습니다. 처음 한 번 **"itda-hyve 가 위치를 사용하려고 합니다"** 창이 뜨면 **허용** 하세요(Windows 는 설정 > 개인 정보 및 보안 > 위치에서 "앱이 위치에 액세스하도록 허용"과 "데스크톱 앱에서 위치에 액세스하도록 허용"). 허용하지 않아도 인터넷 주소(IP)로 시·도 수준까지 추정합니다. 정밀 좌표는 구 단위로 반올림해서만 전달하고 기록에 남기지 않습니다.

시·군·구 판정에 쓰는 경계 데이터: 통계청 SGIS 행정동 경계(공공누리 제1유형) · [vuski/admdongkor](https://github.com/vuski/admdongkor)(CC BY 4.0)를 시·군·구 단위로 병합·단순화해 사용합니다.
