# itda-hyve 설치 가이드

Claude Desktop(Cowork) 이 내 PC 의 네트워크로 웹을 읽고 메일을 주고받게 해 주는 작은 프로그램입니다. 설치 파일 하나로 끝나며, 10분이면 됩니다.

## 준비물

- Claude Desktop (macOS 12 이상 또는 Windows 10/11)
- 메일 계정의 **앱 비밀번호** (일반 비밀번호가 아닙니다)
  - 네이버: 메일 > 환경설정 > POP3/IMAP 설정에서 IMAP 사용 → 2단계 인증을 켰다면 "애플리케이션 비밀번호"
  - Gmail: Google 계정 > 보안 > 2단계 인증 > 앱 비밀번호(16자리)
  - 다음/카카오: 메일 환경설정 > IMAP/POP3 사용 → IMAP 전용 비밀번호
  - iCloud: appleid.apple.com > 로그인 및 보안 > 앱 암호
  - 네이트: 메일 > 모바일 관리 > IMAP 사용 체크 (일반 비밀번호 사용)

## 1. 설치

아직 코드 서명을 하지 않은 판이라 처음 열 때 macOS·Windows 가 경고합니다. 아래 방법으로 한 번만 넘기면 됩니다.

### macOS

1. 내 Mac 에 맞는 파일을 받습니다 — [Apple Silicon(M1 이후)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-darwin-arm64.app.zip) 또는 [Intel](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-darwin-amd64.app.zip). 늘 최신 판이 받아집니다. 어느 쪽인지 모르면 왼쪽 위  > 이 Mac 에 관하여 > 칩 항목을 봅니다(Apple M… 이면 Apple Silicon).
2. 압축을 풀고 `itda-hyve.app` 을 **응용 프로그램** 폴더로 옮깁니다.
3. 처음 열면 "Apple 이 … 악성 코드가 없음을 확인할 수 없습니다"(macOS 14 이하는 "확인되지 않은 개발자") 창이 뜹니다. **완료**(또는 취소)를 누른 뒤 시스템 설정 > 개인정보 보호 및 보안 > 아래쪽 **"그래도 열기"** → 암호 입력 → 다시 뜨는 창에서 **열기**. 한 번만 하면 됩니다.

#### 마크다운(md) 문서를 itda-hyve 문서로 열기 (macOS)

`itda-hyve.app` 안에 문서 창만 따로 여는 앱 **itda-hyve 문서** 가 들어 있습니다. 함께 옮겨지고 함께 지워집니다.

- **한 번 열기**: md 파일을 오른쪽 클릭 > **다음으로 열기** > **itda-hyve 문서**. 이미 창이 떠 있어도 파일마다 새 창으로 열립니다.
- **늘 이 앱으로 열기**(기본 앱으로 지정): md 파일 하나를 고르고 ⌘I(정보 가져오기) > **다음으로 열기** 에서 **itda-hyve 문서** 를 고른 뒤 **모두 변경…** 을 누릅니다. itda-hyve 는 스스로 기본 앱을 바꾸지 않습니다.
- **문서 창만 열기**: Spotlight(⌘Space)에서 "itda-hyve 문서" 를 칩니다. 빈 창에서 열기·새 문서·끌어다 놓기를 할 수 있습니다.
- 따로 승인하지 않아도 됩니다. 위 3번에서 `itda-hyve.app` 을 "그래도 열기" 로 한 번 승인하면 안에 든 itda-hyve 문서도 함께 승인됩니다. 드물게 경고가 다시 뜨면 같은 방법으로 한 번 넘깁니다.

### Windows

1. 내 PC 에 맞는 파일을 받습니다 — [Windows (Intel·AMD, 대부분의 PC)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-windows-amd64.zip) 또는 [Windows on ARM (Snapdragon 등 ARM PC, Mac 의 Parallels)](https://github.com/itda-work/itda-hyve.pub/releases/latest/download/itda-hyve-windows-arm64.zip). 늘 최신 판이 받아집니다. 어느 쪽인지 모르면 설정 > 시스템 > 정보 > **시스템 종류**를 봅니다("ARM 기반 프로세서" 면 ARM). 그래도 모르겠으면 첫 번째 파일을 받으세요 — ARM PC 에서도 돌아갑니다(조금 느릴 뿐입니다). 압축을 풀고, `itda-hyve.exe` 를 `%LOCALAPPDATA%\Programs\itda-hyve\` 에 둡니다(탐색기 주소창에 `%LOCALAPPDATA%\Programs` 를 입력하면 열립니다. `C:\Program Files` 는 관리자 권한이 필요해 회사 PC 에서 막히기 쉽습니다). (한 번 둔 뒤에는 옮기지 마세요. Claude Desktop 에 이 경로가 등록됩니다.)
2. "Windows 의 PC 보호" 창이 나오면 "추가 정보" > "실행".

#### 마크다운(md) 문서를 itda-hyve 문서로 열기 (Windows)

1. itda-hyve 를 열고 **설정**(⚙, 좌하단) › 일반의 **md 파일 연결** 에서 **md 연결 등록** 을 누릅니다. 관리자 권한은 필요 없습니다.
2. **한 번 열기**: md 파일을 두 번 누르면(또는 오른쪽 단추 > **연결 프로그램**) 앱 고르는 창이 뜹니다. **itda-hyve 문서** 를 고르고 **한 번만**. 파일마다 창이 따로 뜹니다.
3. **늘 이 앱으로 열기**: 같은 창에서 **항상** 을 누릅니다. itda-hyve 는 스스로 기본 앱을 바꾸지 않습니다.
4. **문서 창만 열기**: 시작 메뉴에서 "itda-hyve 문서" 를 찾습니다. 빈 창에서 열기·새 문서·끌어다 놓기를 할 수 있습니다.

그만 쓰려면 같은 카드의 **해제** 를 누릅니다. itda-hyve 가 등록한 것만 지워지고 다른 앱의 연결은 그대로입니다.

## 2. 계정 등록

1. `itda-hyve` 를 실행합니다. 창이 하나 뜹니다. 처음 실행하면 `~/.itda/` 폴더와 열쇠 파일이 만들어집니다.
   화면 위 메뉴 막대(macOS)·오른쪽 아래 알림 영역(Windows)에 itda-hyve 아이콘(벌)도 생깁니다. Windows 는 알림 영역의 ^ 안에 숨어 있을 수 있습니다. 창을 닫으면 앱은 끝나지 않고 그 아이콘으로 숨습니다(macOS 는 ⌘H 나 다른 앱의 "다른 항목 가리기" 도 같고, Dock 에서도 빠집니다) — 다시 열 때는 아이콘 > **itda-hyve 열기**, 끝낼 때는 **종료**(macOS 는 창이 떠 있을 때 ⌘Q 도). 로그인할 때마다 조용히 띄워 두려면 **설정**(⚙, 좌하단) › 일반의 **로그인 시 자동 실행** 을 켭니다(아이콘 메뉴에서도 켜고 끌 수 있습니다). macOS 는 처음 켤 때 "백그라운드 항목 추가됨" 알림이 뜨고, 시스템 설정 > 일반 > 로그인 항목에서 꺼 두면 뜨지 않습니다. 앱을 응용 프로그램 폴더로 옮기지 않은 채(다운로드 폴더 등) 실행 중이면 켜지지 않습니다 — 옮긴 뒤 켜세요. 이미 떠 있을 때 다시 실행하면 새로 뜨지 않고 기존 창이 앞으로 옵니다 — 끝내는 중에 다시 실행해 아무 반응이 없으면 잠깐 뒤 한 번 더 실행하세요.
2. **설정**(⚙, 좌하단) › 서비스 › **메일 계정** 에서 **계정 추가** 를 누르고 제공자(네이버, Gmail, …)를 고르면 서버 주소가 채워집니다. 이메일 주소와 앱 비밀번호를 넣습니다.
3. **연결 테스트** 를 눌러 IMAP·SMTP 모두 "성공" 인지 확인합니다. 실패하면 표시된 메시지를 보고 앱 비밀번호·IMAP 사용 설정을 다시 확인합니다.
4. **저장**. 비밀번호는 암호화된 파일(`~/.itda/hyve/vault.enc`)에만 저장되고 설정 파일에는 남지 않습니다. 아직 Claude Desktop 에 등록하지 않았으면(ChatGPT 앱에만 등록한 경우는 빼고) 저장 알림에 **설정 › 연결에서 등록** 링크가 붙습니다 — 눌러서 4장으로 바로 갈 수 있습니다. 대시보드 맨 위의 연결 칩(**Claude Desktop**·**ChatGPT 앱**)도 앱마다 "미등록"·"등록됨 · 실행 안 됨"·"실행 중" 등을 보이고, 누르면 그 앱의 등록 화면으로 갑니다.

열쇠 파일(`~/.itda/master.key`)과 저장 파일의 위치는 **설정**(⚙) › **저장소 파일·복구**에서 볼 수 있습니다. 열쇠 파일을 지우거나 바꾸면 저장된 값을 열 수 없습니다 — 그때는 **설정**(⚙) › 서비스 › **API 키·비밀번호** 에 오류 배지와 **저장소 파일·복구 절에서 복구** 가 뜹니다.

## 3. API 키 등록 (쓰는 스킬이 있을 때만)

공공데이터·검색 같은 스킬은 발급받은 API 키가 필요합니다. **설정**(⚙) › 서비스 › **API 키·비밀번호** 에서 넣습니다.

1. **새 값 등록** 을 누르고 목록에서 필요한 키를 고릅니다. **발급처 열기** 로 키를 받습니다.
2. 받은 키를 값 칸에 붙여넣고 **저장하고 확인** 을 누릅니다. 보내는 곳(허용 호스트)은 자동으로 채워집니다. 이미 등록한 값은 표의 **수정** 으로 바꿉니다.
3. 여러 개를 한 번에 넣으려면 `.env` 내용을 통째로 붙여넣으세요(Ctrl+V / Cmd+V). 무엇이 추가·변경되는지 먼저 보여주고, **반영** 을 눌러야 저장됩니다.

Claude 는 이 값을 볼 수 없습니다. 요청을 보낼 때 itda-hyve 가 채워 넣고, **그 키에 허용된 주소로 나갈 때만** 채웁니다. 대화에서 Claude 가 API 키를 물어보면 알려 주지 말고 이 화면에 넣으세요.

## 4. Claude Desktop 에 등록

1. **설정**(⚙, 좌하단) › **연결** > **등록** 을 누릅니다(이미 등록돼 있으면 버튼이 비활성입니다). 설정 파일에 이 프로그램의 경로가 기록됩니다(기존 설정은 보존, 백업 자동 생성). 같은 화면 아래 **Claude Desktop 설정 파일에 등록된 MCP 서버** 표에서 결과를 확인할 수 있습니다.
2. 설정 패널 위쪽(닫으면 화면 위)에 노란 배너 **Claude Desktop 재시작 대기 중** 이 뜨고, 카드 제목 옆 배지도 "재시작 대기 중" 으로 바뀝니다. **Claude Desktop 을 완전히 종료했다가 다시 엽니다.** 창만 닫으면 안 됩니다 — Windows 는 트레이 아이콘에서 종료, macOS 는 ⌘Q. 종료하면 배너가 닫히고 배지가 "다음 실행 때 반영" 이 되며, 다시 열면 10초 안에 배지가 "적용됨" 으로 바뀌고 "다시 시작해 적용됐습니다" 알림이 뜹니다. 대시보드의 **Claude Desktop** 칩은 "● 실행 중" 이 됩니다(serve 가 떠 있다는 뜻 — 실제 도구 호출은 3단계로 확인합니다).

설정 화면에는 "저장" 단추가 없습니다(계정 추가·새 값 등록 창과 플러그인의 시크릿 허락·설정 폼은 예외) — 바꾸면 바로 저장됩니다(직접 고친 저장 폴더 경로와 숫자는 Enter 를 누르거나 입력란을 벗어날 때). 각 항목이 언제 반영되는지는 카드 제목 옆 배지(즉시 / 다음 호출부터 / Claude Desktop 재시작 필요 / 다음 로그인부터)로 보입니다.
3. 새 대화에서 "등록된 메일 계정 알려줘" 라고 물어보세요. 계정 이름이 나오면 성공입니다.

(선택) 같은 절의 **Aside 연결** 에서 Aside 브라우저의 CLI 를 찾아 함께 등록할 수 있습니다. 브라우저 자동화가 필요한 스킬이 사용합니다.

### (선택) ChatGPT 데스크톱에 등록

ChatGPT 데스크톱(macOS·Windows, Chat·Work·Codex 가 합쳐진 앱)에서도 itda-hyve 를 쓸 수 있습니다.

1. ChatGPT 데스크톱을 설치하고 한 번 실행해 둡니다(설정 폴더 `~/.codex` 가 생깁니다 — 없으면 itda-hyve 가 "먼저 설치" 를 안내합니다).
2. **설정**(⚙) › **연결** › **ChatGPT 데스크톱에 itda-hyve 등록** 에서 **등록** 을 누릅니다. `~/.codex/config.toml` 에 itda-hyve 블록만 들어가고 나머지 내용은 그대로입니다(백업 자동 생성. 해제하면 블록만 지우므로 등록 때 넣은 구분 빈 줄은 남을 수 있습니다). 메일 발송·일정 저장·일정 삭제는 실행 전에 ChatGPT 가 승인을 묻도록 함께 적어 둡니다.
3. 배너 **ChatGPT 재시작 대기 중** 이 뜨면 ChatGPT 앱을 **완전히 종료**(macOS: ⌘Q)했다가 다시 엽니다. ChatGPT 앱의 **설정 › 통합 › 플러그인 › MCP 탭** 에 `itda-hyve` 가 보이면 등록된 것입니다. itda-hyve 대시보드의 **ChatGPT 앱** 칩이 "● 실행 중" 이면 앱이 serve 를 띄운 것입니다(Windows 의 ChatGPT 앱은 Work·Codex 대화를 시작해야 띄우므로, 그 전에는 앱이 켜져 있어도 "등록됨 · 실행 안 됨" 입니다. 터미널 Codex CLI 가 띄운 것은 칩 옆에 "Codex CLI n개" 로 따로 보입니다). 터미널의 Codex CLI 도 같은 설정 파일을 읽으므로, 함께 쓰고 있다면 CLI 세션도 다시 시작하세요(배너는 ChatGPT 앱이 다시 열렸는지만 봅니다).
4. 대화는 **Work 또는 Codex** 에서 하세요. **Chat 에서는 쓸 수 없습니다**(웹 검색으로 새고 "연결되어 있지 않다" 고 답합니다).

ChatGPT 앱의 로그인·설정은 itda-hyve 가 관리하지 않습니다. 설정 › 서비스 › 에이전트의 계정(이미지 생성용)과도 별개입니다. 프로그램을 옮겼으면 같은 카드에서 **다시 등록** 을 누르세요.

같은 카드 아래에는 **내 ChatGPT 계정의 사용량**(5시간·7일 한도의 사용률, 리셋까지 남은 시간, 무료 리셋 개수)이 보이고, 메뉴 막대(Windows 는 알림 영역)에도 **ChatGPT 앱 (내 계정)** 행으로 나옵니다. 등록하지 않아도 ChatGPT 앱에 로그인돼 있으면 보입니다. itda-hyve 는 ChatGPT 앱의 로그인 정보(`~/.codex/auth.json`)를 읽기만 하고 바꾸거나 갱신하지 않습니다 — "토큰이 만료됨" 이 뜨면 ChatGPT 앱을 한 번 열면 됩니다. 사용량 줄 아래 **자세히** 를 펼치면 받은 정보 전체(이메일·플랜·모델별 사용 가능 여부·크레딧 등)를 볼 수 있습니다 — 사용자·계정 ID 는 끝 4자만 보입니다. 에이전트 계정과 같은 ChatGPT 계정이면 메뉴 막대에는 그 에이전트 행 하나로 합쳐 보입니다. 보고 싶지 않으면 카드의 **ChatGPT 앱 사용량 보기** 를 끄세요(끄면 그 파일을 열지 않습니다).

## 5. 사용

Cowork 에서 email / web-reader 스킬이 이 프로그램을 통해 동작합니다. 예:

- "네이버 메일 안 읽은 거 보여줘"
- "3번째 메일 읽어줘"
- "그 메일에 '내일 참석하겠습니다' 라고 회신해줘" → Claude 가 미리보기를 보여주고 확인을 받은 뒤 보냅니다.
- "이 링크 내용 정리해줘 https://…"
- (macOS) "codex에게 해바라기 밭 수채화 한 장 그려 달라고 해줘" → **설정**(⚙) › 서비스 › **에이전트**에서 codex 를 설치하고 같은 절에서 계정을 추가·로그인해 두면 내 ChatGPT 구독으로 이미지를 만들어 연결 폴더에 저장합니다. 약 1분 걸리고, 기다리는 동안 진행 상황을 한 줄씩 알려 줍니다. itda-hyve 대시보드의 **작업** 카드에서도 실행 중·대기·방금 끝난 작업을 볼 수 있고, **작업 보기 →** 를 누르면 설정 › 에이전트의 작업 표(기록·취소)로 갑니다.

Cowork 가 **"Claude가 itda-hyve에서 … 을(를) 사용하려고 합니다"** 창을 띄우면 **항상 허용** 을 권장합니다. 특히 이미지 생성은 작업 상태를 여러 번 확인하므로, 매번 "한 번만 허용" 을 누르면 그때마다 멈춥니다. 메일 발송·일정 삭제처럼 되돌릴 수 없는 일은 도구가 따로 미리보기를 보여 주고 확인을 받습니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| Claude 가 "도구가 없다" 고 함 | 4단계 등록 후 Claude Desktop 을 다시 시작했는지. **설정**(⚙, 좌하단) › 연결에서 등록 경로 확인 |
| "secret_missing" 이라고 함 | 그 이름의 키가 아직 없습니다. 3단계에서 등록하세요 |
| "secret_host_denied" 라고 함 | 그 키가 이 주소로는 나가지 않게 막혀 있습니다. **설정**(⚙) › 서비스 › API 키·비밀번호에서 **허용 호스트** 를 확인하세요 |
| 연결 테스트 IMAP 실패 | 앱 비밀번호가 맞는지, 메일 서비스에서 IMAP 사용을 켰는지 |
| 연결 테스트 SMTP 실패 | 같은 비밀번호로 IMAP 은 되는데 SMTP 만 안 되면 제공자 설정의 SMTP 포트(465/587) 확인 |
| 메일이 반송됨 | 보낸 사람 주소가 계정 주소와 같은지(별칭 발송은 지원하지 않음) |
| 프로그램을 옮겼더니 안 됨 | **설정**(⚙, 좌하단) › 연결에서 **등록**(경로 갱신) 후 재시작 — ChatGPT 데스크톱도 쓰면 그 카드의 **다시 등록** 도 |
| ChatGPT 가 itda-hyve 를 모른다고 함 | Chat 이 아니라 **Work 또는 Codex** 로 대화하는지, 등록 뒤 ChatGPT 앱을 완전히 종료했다 다시 열었는지 |
| (Windows) 프로그램을 옮겼더니 md 가 안 열림 | itda-hyve 를 한 번 열면 md 연결이 새 위치로 저절로 고쳐집니다. 그래도 안 되면 **설정**(⚙, 좌하단) › 일반에서 **md 연결 등록** |

**대시보드**의 **최근 N분 요약**에서 방금 도구가 불렸는지(마지막 호출 n초 전)·몇 번 불렸고 몇 번 실패했는지를 봅니다. 모든 호출은 아래 접힌 **원본 기록**(감사 로그)에 시각·도구·대상·결과로 남습니다(본문·비밀번호는 기록되지 않음). 문의할 때 원본 기록을 펼쳐 캡처해 보내면 빠릅니다.

## 새 판으로 바꾸기

떠 있는 itda-hyve 를 먼저 끝냅니다 — 메뉴 막대·알림 영역 아이콘 > **종료**(창을 닫는 것만으로는 끝나지 않습니다). Windows 는 끝내지 않으면 `itda-hyve.exe` 를 덮어쓸 수 없습니다. 그다음 같은 자리에 새 판을 두고 실행합니다.

## 삭제

1. (Windows 에서 md 연결을 등록했다면) **설정**(⚙, 좌하단) › 일반 > md 파일 연결 > **해제**.
1. **설정**(⚙, 좌하단) › **연결** > **등록 해제** 를 누릅니다. 이 항목만 지워지고 다른 서버와 나머지 설정은 그대로 남으며, 지우기 전 백업을 만듭니다. (Aside 도 같은 화면에서 해제할 수 있습니다.)
2. **설정**(⚙, 좌하단) › 일반에서 **로그인 시 자동 실행** 을 켜 두었다면 끕니다(지우지 않으면 로그인마다 없는 앱을 부르는 등록이 남습니다). 그다음 앱을 끝내고(메뉴 막대·알림 영역 아이콘 > **종료**) 앱을 지웁니다. 설정 폴더 `~/.itda/hyve`(Windows `%UserProfile%\.itda\hyve`)를 지우면 저장된 값까지 사라집니다.
3. `~/.itda/master.key` 는 다른 itda 프로그램도 함께 쓰는 열쇠입니다. **다른 itda 프로그램을 쓰고 있다면 지우지 마세요.** 지우면 그쪽에 저장된 값도 열리지 않습니다.

## 위치와 출처 표시

"여기 날씨" 처럼 현재 위치가 필요한 스킬은 itda-hyve 에 위치를 묻습니다. 처음 한 번 **"itda-hyve 가 위치를 사용하려고 합니다"** 창이 뜨면 **허용** 하세요(Windows 는 설정 > 개인 정보 및 보안 > 위치에서 "앱이 위치에 액세스하도록 허용"과 "데스크톱 앱에서 위치에 액세스하도록 허용"). 허용하지 않아도 인터넷 주소(IP)로 시·도 수준까지 추정합니다. 정밀 좌표는 구 단위로 반올림해서만 전달하고 기록에 남기지 않습니다.
